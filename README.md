# a433-microservices
Repository ini digunakan untuk kebutuhan kelas Belajar Membangun Arsitektur Microservices

Silakan clone dengan perintah berikut.<br>
`git clone -b proyek-pertama https://github.com/dicodingacademy/a433-microservices.git`

Sebelum menjalankan shell script (build_push_image.sh) hal yang harus dilakukan adalah 
1. Membuat personal token github dengan akses "Read" dan "Write" ke Github Packages
2. lakukan export hasil token yang dibuat (melalui terminal) seperti ini
`export GCHR_TOKEN=<token-anda-tanpa-kutip>`
